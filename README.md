# 競合密度マップ

地図に円を描いて業種を選ぶと、**圏内の同業事業所数・1店あたり人口・平均店舗規模**がその場で出る
無料ツール。登録不要・全国対応。出店検討の競合スクリーニングに。

- 業種は産業中分類ベースの14種（飲食店・小売各種・理美容・学習塾・医療・介護など）
- **1店あたり人口を「昼間ベース」と「夜間人口ベース」の両方で出す**（後述）
- 平均店舗規模（従業者数÷事業所数）で、大型店中心か個人店中心かが分かる
- URLに状態が入るのでそのままシェア可能（`?lat=..&lng=..&r=..&ind=..`）
- 完全静的サイト。サーバ計算ゼロ、外部送信は地図タイルと住所検索のみ

## 商圏メーカー・ポスティング部数計算機との関係

[商圏メーカー](https://github.com/hatsu-kawabata/shoken-maker) が「そこに誰が住んでいるか（需要）」、
[ポスティング部数計算機](https://github.com/hatsu-kawabata/posting-calc) が「何部刷って何件返るか（実行）」に
答えるのに対し、本ツールは「**すでに誰が獲りに来ているか（供給）**」に答える。3本目で需給の両側が揃う。

前集計済みメッシュ資産を再利用しており、新宿駅1km圏の世帯数が商圏メーカーの公開値（17,579世帯）と
一致することをテストで固定している。

### 全国合計は公表確定値と一致する

取り込み漏れ・二重計上の一撃検出として、全国合計を政府の公表値に対してテストで固定している。
差はいずれもメッシュ境界の秘匿・合算処理に由来し、百万分の一未満。

| | 公表確定値 | 本ツールの集計 | 差 |
|---|---|---|---|
| 事業所数（全産業） | 5,288,891 | 5,288,889 | 2 |
| 従業者数（全産業） | 62,427,908 | 62,427,891 | 17 |
| 常住人口 | 126,146,099 | 126,146,090 | 9 |

## 分母について（重要）

常住（夜間）人口だけを分母にすると繁華街・オフィス街で数字が壊れる。
新宿駅1km圏は夜間人口24,300人に対し飲食店2,367軒＝「10人に1店」となり、
奥多摩の山中（120人/店）が自由が丘（138人/店）より過密に見えてしまう。

そこで **昼間人口の代理 = 常住人口 ＋ 全産業従業者数** を主の分母にしている。

| 半径1km | 常住人口 | 全産業従業者 | 飲食店 | 1店/夜間 | 1店/昼間代理 |
|---|---|---|---|---|---|
| 新宿駅 | 24,300 | 384,455 | 2,367 | 10 | 173 |
| 自由が丘駅 | 52,984 | 24,014 | 385 | 138 | 200 |
| 武蔵小杉駅 | 74,014 | 47,884 | 416 | 178 | 293 |

**これは代理指標であって昼間人口そのものではない。** 同じ区画に住みかつ働く人を二重に数え、
買い物客・観光客を含まない。正確な昼間人口は国勢調査の従業地・通学地集計（1kmメッシュ）にある。

## 構成

```
scripts/build_data.py  人口(国調2020) + 事業所(経セ2021) を1次メッシュ単位でマージ
scripts/test.mjs       メッシュ集計と需給指標の純関数テスト(18本)
web/mesh.js            500mメッシュの座標計算と円内集計(純関数)
web/compete.js         14業種・1店あたり人口・需給インデックス・平均店舗規模・昼間代理(純関数)
web/app.js             地図UI・業種選択・URL共有
```

## 開発

```sh
STATS_ID=T001163 python3 ~/shoken_maker/scripts/fetch_mesh.py --sweep  # 事業所zipを raw/ へ
python3 scripts/build_data.py        # 人口とマージして web/data/ を生成
node --test scripts/test.mjs         # テスト
python3 -m http.server 8139 -d web   # ローカル起動 → http://localhost:8139
```

## データ

| | statsId | 測地系 |
|---|---|---|
| 事業所・従業者 | T001163（令和3年経済センサス‐活動調査 産業中分類別、500mメッシュ） | JGD2011 |
| 人口・世帯 | T001141（令和2年国勢調査 人口及び世帯、500mメッシュ） | JGD2011 |

**両者は必ず同じ測地系で揃える。** e-Statは同一調査・同一解像度でもJGD2000版とJGD2011版を
並存させており、混ぜると同じメッシュコードがわずかに違う領域を指す。

## 精度と免責

- **事業所は店舗と一致しない**。本社・事務所・無店舗事業所を含む
- 事業所は2021年6月1日、人口は2020年10月1日時点。**直近の開店・閉店は反映されない**（基準日が8か月ずれる）
- 秘匿処理は実測の範囲では確認されなかった（事業所1件のセルも従業者数まで公開されている）
- 円内判定はセルを2×2サブ点で近似した重み付き按分
- 数値は概算であり、出店の成否を保証するものではありません
